Política de privacidad

Esta política describe la prueba privada de ParceStudio. Responsable: Carlos Javier Lopez Perez, persona natural, marca ParceStudio. Contacto para consultas o solicitudes sobre datos: donlopezpa@gmail.com.

Datos tratados en el equipo

La aplicación guarda localmente los videos importados, clips exportados, propuestas, ediciones, textos y estados de publicación. También guarda en un archivo de configuración local las claves y tokens que el usuario configure. No hay un servicio de cuentas de ParceStudio ni cobros en esta prueba.

Cuándo salen datos del equipo

  • La transcripción local con Whisper se procesa en el computador. Al elegir funciones de análisis con IA en la nube, se pueden enviar texto de transcripciones y cuadros seleccionados del video a Anthropic. Otras funciones configuradas por el usuario pueden enviar audio para transcripción a OpenAI.
  • Al descargar material mediante un enlace, la aplicación se comunica con la fuente de video correspondiente.
  • Al conectar una red social, TikTok o Meta reciben la solicitud de autorización y devuelven un token. Si el usuario elige enviar un clip, la aplicación transmite el archivo y los datos necesarios a la red seleccionada. TikTok puede recibirlo como borrador para que el titular termine la publicación allí.

Estas transmisiones se realizan para ejecutar la función que el usuario elige. Cada proveedor aplica además su propia política de privacidad.

Conservación y seguridad

Los proyectos y archivos locales permanecen hasta que el usuario los elimina. Los tokens se mantienen en el archivo .env del equipo y se usan para las cuentas autorizadas; el usuario debe proteger el acceso a su computador y puede revocar la autorización desde la plataforma correspondiente. Esta versión no incluye sincronización en la nube ni telemetría propia. Si se añade cualquiera de esas funciones, esta política se actualizará antes de activarlas.

Sitio web

El sitio informativo se aloja en GitHub Pages. ParceStudio no agrega formularios de registro ni herramientas propias de seguimiento al sitio. GitHub puede tratar datos técnicos de las visitas según su propia política.

Solicitudes y cambios

Para consultar los datos tratados o solicitar ayuda para eliminarlos, escribe a donlopezpa@gmail.com. Una distribución a otros creadores exigirá revisar esta política para reflejar las funciones y proveedores realmente habilitados entonces.
